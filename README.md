# CHOFLIX PROMPTER

**방송용 프롬프터 소프트웨어**

카메라 앞 하프미러 리그를 쓰는 스튜디오 환경을 위한 프롬프터입니다.<br>
원고 작성부터 주행 제어, 엔지 대응까지 한 프로그램에서 처리합니다.

`Electron` · `Windows 10 / 11` · `MIT`

**[⬇ 최신 배포본 받기 (Releases)](https://github.com/fmj96/choflix-prompter/releases/latest)**

## 받아서 쓰기

[Releases](https://github.com/fmj96/choflix-prompter/releases/latest) 에서
`ChoflixPrompter-Setup-<버전>.exe` 를 받아 실행하십시오.

- 관리자 권한이 필요 없습니다 — 사용자 폴더에 설치됩니다
- 인터넷이 필요 없습니다 — 음성 추종 모델까지 설치 파일에 들어 있습니다
- 첫 실행에서 SmartScreen 이 뜨면 `추가 정보` → `실행` 을 누르십시오 (서명되지 않은 실행 파일)

**업데이트** — 설정 패널 맨 아래 `업데이트` 칸에서 합니다.
인터넷이 되면 GitHub 에서 받아 설치하고, 인터넷이 없는 PC 는 USB · NAS 에 둔 설치 파일을 고르면 됩니다.
설정과 원고는 그대로 남습니다.

## v3.0 — WPF 에서 옮겨 온 이유

이전 버전은 C# WPF 로 만들었고, **주행 중 글자가 미세하게 떨리는 문제**를 끝내 해결하지 못했습니다.

원인은 소수점 픽셀 위치였습니다. 60Hz 화면에서 속도 75 px/s 면 프레임당 1.25픽셀을 움직여야 하는데,
WPF 는 글자를 픽셀 격자에 맞춰 그리기 때문에 1픽셀과 2픽셀을 번갈아 움직입니다.
프레임은 60fps 로 다 나오는데 눈에는 떨려 보이는 상태였습니다.

브라우저 엔진은 **소수점 픽셀 위치에 글자를 제대로 그립니다.** 같은 방식으로 옮기니 그대로 해결됐습니다.

부수적으로 얻은 것도 있습니다.

| 항목 | WPF | Electron |
|---|---|---|
| 소수점 픽셀 이동 | 격자에 맞춰 스냅 | 그대로 그림 |
| 어절 단위 줄바꿈 | 글자 사이에 보이지 않는 문자 삽입 | `word-break: keep-all` 한 줄 |
| 편집창 줄 간격 | TextBox 미지원 → RichTextBox 로 교체 필요 | CSS 그대로 |

## 주요 기능

**주행**
- 매 프레임 소수점 단위 이동 — 속도가 주사율의 배수가 아니어도 균일합니다
- 주행 중에도 글자 크기·속도 조절, 읽던 지점의 진행 비율을 기준으로 위치를 되잡습니다

**시간 관리**
- **누적 진행 시간이 엔지 재독을 제외하고 계산됩니다.** 되감아 다시 읽는 동안에는 늘지 않고,
  이전 최대 지점을 넘어서면 다시 흐릅니다. 누적 시간이 곧 편집 후 완성본 길이에 가까운 값이 됩니다

**하프미러 리그**
- 모니터 자체 반전 / 소프트웨어 반전 중 선택 — 이중 반전 차단
- 복제·확장 출력 배치 모두 지원, 프리셋 버튼으로 한 번에 설정

**편집**
- **글자를 끌어 고른 뒤 색을 입힙니다** — 강조할 단어를 눈에 띄게 (v3.2)
- **편집창의 줄 배열이 프롬프터 화면과 똑같습니다** — 한 줄에 들어가는 글자가 같습니다 (v3.2.1)
- 편집창에 프롬프터와 같은 글꼴·크기·**줄 간격**·색·정렬·굵기가 그대로 적용됩니다
- 설정 패널은 상단 `설정` 버튼으로 열고 닫습니다 — 평소에는 편집창을 넓게 씁니다
- 주행을 멈추고 나오면 읽던 줄로 커서가 자동 이동합니다
- 원고 5초마다 자동 보존 (임시 파일 교체 방식)

**운용**
- 모든 단축키 재지정 가능, 설정은 파일로 유지
- 주행 중 운영자 바는 나타나지 않습니다 — `Tab` 으로만 켜고 끕니다
- 주행 중에는 마우스 커서를 감춥니다. 멈추면 다시 보입니다 (v3.2.2)
- 마우스: 클릭(시작/정지) · 드래그(이동) · 휠(주행 중 속도 / 정지 중 이동)
- 편집 중에도 잔여 · 전체 시간이 표시됩니다 — 커서가 놓인 줄부터 끝까지가 잔여입니다

**설치 · 업데이트** (v3.3)
- 설치 마법사 · 시작 메뉴 · 제거 지원, 관리자 권한 불필요
- 프로그램 안에서 업데이트 — 인터넷(GitHub) 또는 USB · NAS 의 설치 파일
- 확인만 저절로, 받기 · 설치는 운영자가 누를 때만 — 방송 중 갑자기 닫히지 않습니다

**음성 추종** (v3.1)
- 강의자가 읽는 자리를 음성으로 찾아 주행 속도를 저절로 맞춥니다
- 휠·드래그·속도 조작 등 **무엇이든 손을 대면 즉시 수동**으로 돌아옵니다 (`F8` 로 재개)
- 애드립이나 NG 로 대본을 벗어나면 **마지막 자리를 지킵니다** — 혼자 앞서 가지 않습니다
- 인식은 별도 프로세스에서 돕니다. 주행 프레임에 영향 없음 (실측 부하 한 코어의 3~4%)
- 인터넷이 필요 없습니다 — 모델이 배포본에 들어갑니다

## 개발 실행

```bash
npm install
npm start
```

Mac 에서 Windows 배포본만 만들 때는 Mac 용 Electron 을 받지 않습니다.
이 경우 `npm start` 는 동작하지 않으므로, 화면 확인은 브라우저 껍데기로 합니다.

```bash
npm install --ignore-scripts
python3 -m http.server 5178
```

띄운 뒤 `http://localhost:5178/dev/preview.html` 을 엽니다.
`src/` 를 그때그때 읽어 오므로 원본을 고치면 새로고침만 하면 됩니다.
편집 콘솔의 배치 · 시간 계산 · 운영자 바까지 확인되고,
파일 저장 · 모니터 배치 · 확장 배치 출력 창은 흉내만 냅니다.

## 배포본 만들기

```bash
npm run build:win     # dist/ChoflixPrompter-win32-x64/  (폴더)
npm run build:setup   # dist/ChoflixPrompter-Setup-<버전>.exe  (설치 파일, makensis 필요)
```

**Mac 에서 Windows 배포본을 만들 수 있습니다.** 만들어진 폴더를 통째로 압축해
프롬프터 PC 로 옮기고 `ChoflixPrompter.exe` 를 실행하면 됩니다.
설치 과정이 없고 .NET 런타임 같은 사전 조건도 없습니다.

> 폐쇄망 PC 에서는 `npm install` 이 불가능하므로 반드시 인터넷이 되는 기기에서 빌드하십시오.

## 기본 단축키

| 동작 | 키 |
|---|---|
| 음성 추종 켜기 / 끄기 | `F8` |
| 프롬프터 (처음부터 / 중간부터) | `F9` / `Shift + F9` |
| 시작 / 정지 | `Space` |
| 처음으로 | `F10` |
| 속도 내림 / 올림 | `↑` / `↓` |
| 미세 이동 | `Shift + ↑ ↓` |
| 반 화면 이동 | `PgUp` / `PgDn` |
| 글자 작게 / 크게 | `←` / `→` |
| 운영자 바 | `Tab` |
| 프롬프터 닫기 | `Esc` |

전부 재지정할 수 있습니다.

## 구조

```
src/
  main.js       창 관리 · 모니터 배치 · 파일 저장 · 새로고침 차단
  preload.js    렌더러에 열어 주는 최소 통로
  index.html    편집 콘솔 + 복제 배치용 출력
  stage.html    확장 배치용 출력 창
  engine.js     주행 엔진 (두 창이 공유)
  app.js        콘솔 동작 · 설정 · 단축키
  style.css     부조 콘솔 테마
  richtext.js   색 있는 원고 다루기 · 정화 (보안 경계)
  tracker.js    들린 말 → 대본 위치 (음성 추종의 심장)
  follow.js     대본 위치 → 주행 속도
  mic.js        마이크 → 0.2초 조각
  mic-worklet.js  오디오 스레드에서 조각 모으기
  asr-worker.js   음성 인식 전담 프로세스
  update.js     업데이트 — GitHub 확인 · 받기 · 설치 파일 실행
installer/
  setup.nsi     설치 파일 (NSIS)
dev/
  preview.html  브라우저로 편집 콘솔만 열어 보는 껍데기 (배포본에 미포함)
```

주행 엔진은 한 벌이며, 복제 배치에서는 콘솔 창 안에서, 확장 배치에서는 출력 창에서 돕니다.
확장 배치일 때 조작 명령과 상태 보고만 두 창 사이를 오갑니다.

### 새로고침 차단

`F5` 와 `Ctrl+R` 을 주 프로세스에서 막습니다.
브라우저로만 쓰면 방송 중에 원고가 통째로 날아갈 수 있는데,
감싸서 얻는 것 중 이것이 가장 큽니다. 주소창 노출과 전체화면 이탈도 함께 해결됩니다.
