v2 에서 올라오신 경우

v3.0 부터 프로그램의 속이 완전히 바뀌었습니다(C# WPF → Electron). 조작 방법과 화면 구성은 거의 그대로지만, 설치 방법과 기본 단축키가 달라졌습니다. 1장과 8장을 먼저 보십시오.

1설치와 실행

필요한 것

Windows 10 또는 11 뿐입니다. .NET 도, 별도 런타임도 필요하지 않습니다. 프로그램이 실행에 필요한 모든 것을 폴더 안에 담고 있습니다.

v2 와 달라진 점

v2 까지는 .NET 8 런타임을 미리 깔아야 했고 run.bat · publish.bat 으로 실행했습니다. v3 은 그 과정이 모두 없어졌습니다.

실행

  1. 받은 압축 파일을 프롬프터 PC 의 원하는 위치에 풉니다 (예: C:\Prompter)
  2. 폴더 안의 ChoflixPrompter.exe 를 두 번 누릅니다

설치 과정도, 관리자 권한도 필요 없습니다. 창은 최대화된 상태로 열립니다. 폴더째 USB 로 옮겨 다른 PC 에서 실행해도 그대로 동작합니다.

폴더 전체를 함께 옮기십시오

ChoflixPrompter.exe 하나만 꺼내면 실행되지 않습니다. 같은 폴더의 resources · locales 와 .dll 파일들이 함께 있어야 합니다. 바탕화면에 두고 쓰시려면 바로가기를 만드십시오.

새 버전으로 바꾸기

  1. 프롬프터가 실행 중이면 닫습니다
  2. 기존 폴더를 통째로 지우거나 이름을 바꿔 둡니다
  3. 새 폴더를 풀어 놓고 실행합니다

설정과 원고 보존본은 프로그램 폴더가 아니라 %APPDATA% 에 따로 있으므로 (11장 참고) 폴더를 지워도 설정과 원고는 남습니다.

배포본 만들기 — 개발자용

프롬프터 PC 는 인터넷이 없으므로 빌드는 항상 Mac 에서 합니다.

# 처음 한 번
npm install --ignore-scripts

# 배포본 만들기
npm run build:win
→ dist/ChoflixPrompter-win32-x64/

만들어진 폴더를 압축해 USB 나 NAS(192.168.10.100)로 옮깁니다. 자세한 내용은 저장소의 BUILD.md 를 보십시오.

프롬프터 모드

선택한 배치에 따라 두 가지로 동작합니다.

  • 복제 — 이 창이 전체화면(작업표시줄까지 덮음)이 됩니다
  • 확장 — 프롬프터 모니터에 전체화면 창이 따로 열리고, 운영자 화면에는 편집 콘솔이 그대로 남습니다

운영자 바 (복제 배치)

화면 하단에 속도 조절, 가운데 큼직한 누적 진행 시간, 오른쪽에 잔여시간과 시작 · 처음으로 · 닫기 버튼이 있습니다. 누적 시간은 멀리서도 읽히도록 크게 표시되므로, 강의나 강연처럼 진행자가 경과 시간을 직접 확인해야 하는 경우 바를 켜 두고 쓰시면 됩니다.

운영자 바는 Tab 으로만 켜고 끕니다

프롬프터를 열면 꺼진 상태로 시작하며, 저절로 나타나거나 사라지지 않습니다. 출연자가 보는 화면에 조작 UI 가 예고 없이 튀어나오지 않게 하기 위한 것입니다.

화면 맨 아래 3px 진행 스트립은 항상 남아 있어, 운영자 바가 꺼져 있어도 위치는 확인할 수 있습니다.

3원고 작성

표기 규칙

특별한 표기 없이 줄 단위로 그대로 표시됩니다. 빈 줄은 문단 간격이 됩니다. 원고에 지시문이나 표시를 위한 기호를 넣을 필요가 없습니다.

편집창 미리보기

편집창에 프롬프터와 같은 글꼴 · 크기 · 줄 간격 · 색 · 정렬 · 굵기가 그대로 적용됩니다. 글자 크기는 화면 폭 대비 편집창 폭 비율로 줄여 보여 주므로, 편집창에서 보이는 줄바꿈 위치가 실제 프롬프터와 거의 같습니다.

필요 없으면 표시 카드의 편집창에 이 스타일 그대로 표시 를 끄십시오. 평범한 검정 배경 편집기로 돌아갑니다.

어절 단위 줄바꿈

한글은 음절 단위로 끊어도 된다고 보는 것이 기본 동작이라, 그냥 두면 안녕하십니 / 까 처럼 어절 중간이 갈라집니다. 프롬프터에서는 읽기 흐름이 끊기는 문제입니다.

이 옵션을 켜면 어절 안쪽에서 줄이 바뀌지 않습니다. 한 줄에 도저히 들어가지 않는 긴 어절만 예외적으로 끊깁니다.

v3 부터 편집창에도 적용됩니다

v2 에서는 글자 사이에 보이지 않는 문자를 끼워 넣는 방식이라 편집 중인 원고에는 쓸 수 없었습니다. v3 은 표시 방식만 바꾸므로 원고 내용에 아무것도 섞이지 않고, 편집창과 프롬프터가 똑같이 줄을 바꿉니다.

불러오기 · 저장

원고창 머리말 오른쪽의 불러오기 · 저장 으로 txt 파일을 주고받습니다. 파일은 UTF-8 로 읽고 씁니다.

한글이 깨져 보인다면

옛날 ANSI(CP949)로 저장된 파일입니다. 메모장에서 열어 다른 이름으로 저장 → 인코딩 UTF-8 로 바꾼 뒤 다시 불러오십시오.

원고 자동 보존

작업 중인 원고는 자동으로 보존됩니다. 정전이나 강제 종료로 창이 닫혀도 다시 실행하면 마지막 원고가 복원되고, 원고창 머리말 오른쪽에 이전 원고를 복원했습니다 · 08-21 09:15 가 표시됩니다.

보존 시점설명
5초마다내용이 바뀐 경우에만 기록합니다
프롬프터 시작 시방송에 나간 원고는 확실히 남습니다
정상 종료 시—
안전장치

임시 파일에 먼저 쓴 뒤 바꿔치우는 방식이라, 저장 도중 전원이 나가도 이전 보존본이 깨지지 않습니다. 다만 보존본은 한 벌만 유지되므로, 여러 원고를 보관하시려면 저장 으로 따로 파일을 만드십시오.

4리그 설치 설정

제어판 맨 아래 출력 · 미러 카드에서 설정합니다. 리그를 설치할 때 한 번 잡아 두면 되는 항목입니다.

반전은 누가 처리하는가

하프미러 유리에 반사시키는 리그는 화면을 좌우로 뒤집어야 글이 바로 읽힙니다. 이 반전을 모니터가 처리할지, 프로그램이 처리할지 먼저 정해야 합니다.

선택프로그램 출력쓰는 경우
모니터 자체 반전 기능 사용정방향모니터에 좌우반전 기능이 있는 경우
소프트웨어로 반전뒤집힌 화면반전 기능이 없는 모니터
둘 다 켜면 두 번 뒤집힙니다

모니터 반전 기능을 켜 두셨다면 소프트웨어 반전은 반드시 꺼야 합니다. 모니터 자체 반전 기능 사용 을 고르면 소프트웨어 반전이 자동으로 꺼지고 체크박스도 비활성화됩니다. 방송 중에 발견하면 대응하기 어려운 종류의 실수라 프로그램에서 막아 두었습니다.

모니터 설정이 풀리는 기종

입력을 전환하거나 전원을 다시 넣으면 반전 설정이 초기화되는 모니터가 있습니다. 방송 전에 유리에서 글이 바로 읽히는지 한 번 확인하는 편이 안전합니다.

출력 배치

배치화면 구성
복제이 창이 전체화면이 되어 두 모니터가 같은 그림을 봅니다
확장프롬프터 모니터에 전체화면 창이 따로 열리고, 운영자 화면에는 편집 콘솔이 남습니다

모니터 반전 기능을 쓰신다면 복제 배치로 충분합니다. 프로그램이 정방향으로 출력하므로 운영자 화면도 정상으로 보입니다. 확장 배치는 주행 중에도 원고를 편집하거나 다음 꼭지를 미리 볼 때 유용합니다.

확장으로 바꾸려면 Win + P → 확장 으로 설정한 뒤 모니터 다시 검색 을 누르십시오.

하프미러 리그 프리셋

하프미러 리그 프리셋 적용 버튼을 누르면 다음이 한 번에 잡힙니다.

  • 모니터 자체 반전 사용 (소프트웨어 반전 OFF)
  • 검정 배경 + 흰 글씨 — 유리 반사 대비가 가장 좋습니다
  • 큐 라인 표시 ON, 가운데 정렬

색

글자색 · 배경색 · 큐 라인 색을 각각 지정합니다. 색 견본을 누르거나 #RRGGBB 로 직접 입력합니다. 글자색 ↔ 배경색 맞바꾸기 버튼으로 흑백을 뒤집을 수 있습니다.

하프미러 리그 권장

검정 배경 + 흰 글씨가 반사 대비가 가장 좋습니다. 눈이 부시다는 의견이 있으면 글자색을 연노랑(#FFF3C4)으로 낮춰 보십시오.

큐 라인

출연자가 시선을 두는 기준선입니다. 원고는 이 선에 맞춰 올라옵니다. 위치는 화면 상단 대비 10 ~ 70 % 범위에서 조절하며 기본값은 35 % 입니다. 출연자 신장이나 카메라 높이에 따라 조정하십시오.

화면에 잔여시간 표시

프롬프터 화면 우측 상단에 누적 · 잔여 시간을 흐리게 표시합니다. 출연자가 남은 분량을 가늠하는 데 쓰입니다. 필요 없으면 끄십시오.

부드러운 주행

원고는 매 프레임 소수점 단위로 움직입니다. 60Hz 화면에서 속도 75 px/s 면 한 프레임에 1.25픽셀을 가야 하는데, 이를 1픽셀과 2픽셀로 번갈아 처리하면 프레임은 다 나오면서도 눈에는 떨려 보입니다.

v3 의 표시 엔진은 소수점 픽셀 위치에 글자를 제대로 그리므로, 속도가 주사율의 배수가 아니어도 균일하게 흐릅니다. v2 까지 남아 있던 미세한 떨림은 이 방식으로 바꾸면서 해결되었습니다.

v2 의 비트맵 캐시 옵션은 없어졌습니다

원고를 그림으로 한 번 그려 두고 밀던 방식입니다. 긴 원고에서는 크기 상한에 걸려 실제로는 켜지지 않았고, v3 에서는 필요가 없어져 항목째 없앴습니다.

6주행 조작

두 가지 시작 방식

방식동작쓰는 경우
처음부터원고 맨 앞으로 되감고 시작. 누적 시간 초기화새 테이크 시작

잔여 · 전체

"지금 시작해서 한 번도 멈추지 않으면 몇 초 걸리는가"입니다. 출연자의 실제 낭독 속도와는 무관하며, 속도 · 글자 크기 · 줄 간격 · 여백을 바꾸면 즉시 다시 계산됩니다. 정지 중에는 시간이 흐르지 않습니다.

v3.0.1 부터 편집 중에도 나옵니다

프롬프터를 열지 않은 상태에서도 잔여 · 전체가 표시됩니다. 실제 출력이 나갈 모니터와 같은 폭으로 원고 높이를 따로 재기 때문에, 프롬프터를 열었을 때와 같은 값이 나옵니다.

이때 잔여는 편집창 커서가 놓인 줄부터 끝까지입니다. 프롬프터 (중간부터) 로 시작할 때의 남은 시간과 기준이 같습니다. 커서를 옮기면 잔여도 따라 바뀝니다.

누적 — 엔지 재독을 빼고 셉니다

누적은 벽시계 시간이 아니라 원고를 얼마나 새로 읽어 나갔는지를 잽니다. 엔지가 나서 위로 되감아 다시 읽는 동안에는 시간이 늘지 않고, 이전에 도달했던 가장 먼 지점을 넘어서는 순간부터 다시 올라갑니다.

엔지 되감기로 쓰이는 경우가 대부분이라, 여기서 초기화하면 되감을 때마다 누적이 날아갑니다. 새 테이크를 시작하실 때는 누적 숫자를 클릭하거나 처음부터 로 여십시오.

원고창 머리말의 「낭독 추정」

이쪽은 글자 수 기준입니다. 공백 제외 글자 수를 분당 330자로 나눈 값으로, 한국어 뉴스 낭독 속도의 대략적인 평균입니다. 아나운서마다 편차가 크므로 참고값으로만 보십시오.

낭독 추정과 전체가 다르게 나오는 것은 정상입니다 — 앞은 글자 수, 뒤는 설정한 주행 속도로 계산합니다. 리허설로 읽어 보시고 두 값이 비슷해지는 속도를 찾아 두시면 잔여 시간이 실제 방송 시간과 맞아떨어집니다.

재지정 방법

제어판 단축키 카드에서 오른쪽 버튼을 누르고 원하는 키를 입력하면 바로 지정됩니다.

  • Esc — 취소
  • Delete — 지정 해제
  • 이미 쓰이는 조합을 넣으면 기존 지정이 자동으로 비워집니다

버튼에 표시되는 단축키 표기는 실제 지정값을 따라가므로, 키를 바꾸면 표기도 함께 바뀝니다. 기본값으로 되돌리기 로 위 표의 상태로 복구할 수 있습니다.

9실전 운용 절차

최초 설치 시 (한 번만)

  1. 모니터의 좌우반전 기능을 켭니다 (있는 경우)
  2. 제어판 맨 아래 출력 · 미러 → 하프미러 리그 프리셋 적용
  3. 출력 배치 선택 — 복제 또는 확장
  4. 이전 버전을 쓰던 PC 라면 단축키 카드의 기본값으로 되돌리기
  5. 프롬프터를 열고 유리에서 글이 바로 읽히는지 확인
  6. 출연자 위치에서 글자 크기와 큐 라인 위치를 맞춥니다

설정은 자동 저장되므로 다음 실행에도 유지됩니다.

방송 전 점검

  1. 원고를 붙여 넣거나 불러오기
  2. 원고창 머리말의 줄 수 · 글자 수 · 낭독 추정 확인
  3. 상단의 전체 시간이 방송 길이에 맞는지 확인 — 다르면 속도를 조절합니다
  4. 프롬프터 (처음부터) F9 로 열기
  5. 리허설로 한 번 읽어 보며 속도 조절
  6. 누적 숫자를 클릭해 0 으로 초기화
3번은 v3.0.1 부터 가능해진 절차입니다

프롬프터를 열기 전에도 전체 시간이 나오므로, 원고를 넣자마자 분량을 가늠할 수 있습니다.

복제 배치 사용 시

편집 화면도 출연자 모니터에 그대로 나갑니다. 방송 직전에 반드시 프롬프터 모드로 들어가 두십시오.

생방송 중 원고 수정

  1. Space 로 정지
  2. Esc 로 편집 모드 복귀
  3. 커서가 정지한 시점에 화면 한가운데 있던 줄로 자동 이동합니다. 그 줄은 편집창 중앙보다 살짝 위에 놓입니다
  4. 수정 후 Shift + F9 (중간부터)로 복귀 — 커서가 놓인 줄부터 이어 읽습니다

긴 원고에서 그 문장을 눈으로 찾아다닐 필요가 없습니다.

엔지 대응

  1. Space 로 정지
  2. PgUp 또는 Shift + ↑ 로 되감기
  3. Space 로 재개

되감은 구간을 다시 읽는 동안 누적 시간은 늘지 않습니다. 이전 최대 지점을 넘어서면 다시 흐르므로, 누적 시간이 완성본 길이에 가까운 값으로 유지됩니다.

10문제 해결

증상원인과 대처
유리에서 글이 거꾸로 보인다 모니터 반전과 소프트웨어 반전이 둘 다 켜져 두 번 뒤집힌 상태입니다. 출력 · 미러 → 모니터 자체 반전 기능 사용 을 선택하십시오.
어제는 됐는데 오늘 반전이 안 된다 모니터 설정이 전원 재투입으로 풀렸을 수 있습니다. 모니터 OSD 를 확인하십시오.
F9 를 눌러도 안 열린다 이전 버전에서 저장된 단축키가 남아 있습니다. 단축키 → 기본값으로 되돌리기 를 누르거나, 표시된 키(F5)를 그대로 쓰십시오.
설정을 바꿨는데 반영되지 않는다 저장된 설정이 새 기본값보다 우선합니다. 해당 항목을 직접 바꾸거나 기본값으로 되돌리기를 쓰십시오.
확장 배치에서 모니터가 하나만 잡힌다 Win + P → 확장 으로 바꾼 뒤 모니터 다시 검색 을 누르십시오.
주행 중 운영자 바가 안 보인다 의도된 동작입니다. Tab 으로 띄우십시오.
불러온 원고의 한글이 깨진다 ANSI(CP949)로 저장된 파일입니다. 메모장에서 UTF-8 로 다시 저장하십시오.
어절이 줄 끝에서 갈라진다 표시 카드의 어절 단위 줄바꿈 을 켜십시오.
프로그램이 실행되지 않는다 ChoflixPrompter.exe 만 따로 꺼내 두지 않았는지 확인하십시오. 폴더 전체가 함께 있어야 합니다.
exe 아이콘이 예전 것으로 보인다 윈도우 아이콘 캐시 문제입니다. 폴더를 다른 이름으로 풀거나 탐색기를 다시 시작하십시오.
글자가 튀거나 스크롤이 끊긴다 다른 프로그램이 GPU 를 점유하고 있을 수 있습니다. 방송용 PC 에서는 불필요한 프로그램을 닫아 두십시오.

설정 파일을 지우면 모든 설정이 기본값으로 돌아갑니다. 다른 PC 로 설정을 옮기려면 config.json 을 복사하십시오.

주소창에 %APPDATA% 를 입력하면 해당 폴더가 열립니다.

설정 파일이 깨진 경우

프로그램은 설정을 읽지 못하면 조용히 기본값으로 시작합니다. 설정 저장에 실패해도 작업을 막지 않습니다. 방송을 멈추게 하지 않는 것이 우선이기 때문입니다.

v2 에서 올라오신 경우

v2 의 설정은 %APPDATA%\CHOFLIX\Prompter\ 에 있었습니다. v3 은 다른 폴더를 쓰므로 이전 설정을 이어받지 않습니다. 원고는 v2 폴더의 last_script.txt 를 열어 옮겨 붙이시면 됩니다.
